# Проект по БД
## Описание
В рамках проекта получены данные о компаниях и вакансиях с сайта hh.ru, спроектированы 
таблицы в БД PostgreSQL и загружены полученные данные в созданные таблицы.

### Модуль hh_api_empoyers.py
В модуле реализован класс HeadHunterApiEmployers для работы с API HeadHunter, 
подключение к API и поиск работодателя. 

Метод get_employers() получает вакансии с возможностью поиска по ключевому слову и
преобразует их, отбирая необходимые ключи со значениями.

### Модуль hh_api_vacancies.py
В модуле реализован класс для работы с API HeadHunter, подключение к API и получение 
вакансий.

Метод get_vacancies() получает вакансии с возможностью поиска по ключевому слову и
преобразует их, отбирая необходимые ключи со значениями.

### Модуль utils.py
В модуле реализованы:

- функция create_database(), которая обеспечивает подключение PostgresSQL и создает базу данных.
- функция, create_table(), которая обеспечивает подключение к базе данных и создает таблицы.
- функция save_data_to_database(), которая, сохраняет данные о компаниях и вакансиях в базу данных.

### Модуль db_manager.py
В модуле реализован класс DBManager, который подключается к БД PostgreSQL и имеет 
следующие методы:

- get_companies_and_vacancies_count() - получает список всех компаний и количество вакансий у каждой компании;
- get_all_vacancies() - получает список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию;
- get_avg_salary() - получает среднюю зарплату по вакансиям;
- get_vacancies_with_higher_salary() - получает список всех вакансий, у которых зарплата выше средней по всем вакансиям;
- get_vacancies_with_keyword() - получает список всех вакансий, в названии которых содержатся переданные в метод слова, например python.

### Модуль views.py
Модуль - «точка входа», при запуске которого можно выводится результат всех реализованных в проекте функциональностей.

### Подключение к БД PostgreSQL
Необходимо в проекте создать файл с названием ```database.ini```, который содержит следующую
структуру:
```
[postgresql]
host=host
user=user
password=password
port=port
```
## Использование:

1. Клонируйте репозиторий:

Скачать проект можно по ссылке
```
https://github.com/Sermin22/JobSearchDBconnectionProject
```
2. Перейдите в ветку для разработки develop. 
3. Функциональность прописана в Python Package "src".
4. Склонируйте репозиторий к себе на компьютер с помощью команды ```git clone```.
5. Для установки зависимостей используйте команду ```poetry install```.
